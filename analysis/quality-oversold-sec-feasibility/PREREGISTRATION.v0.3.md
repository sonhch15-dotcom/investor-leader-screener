# 품질 우량주 과매도 스크리너 — 사전등록 v0.3

## 문서 상태

- 버전: 0.3
- 기록일: 2026-07-29
- 상태: 이자부 D/E 주석·전체 XBRL fallback 실행 직전
- 수익률 결과 열람·계산: 없음
- `MAX_DEBT_TO_EQUITY`: **미확정**
- 주의: 이 파일은 데이터 타당성 단계의 사전등록이다. 최종 데이터
  커버리지 판정과 지표 정의가 끝난 뒤, 수익률 계산을 시작하기 직전에
  백테스트 최종 사전등록을 새 버전으로 만들고 원격 저장소에 푸시한
  커밋과 서명 태그를 리포트에 인용한다.

## v0.2에서 바뀐 내용

1. 이자부 D/E fallback 결과에 따른 행동을 결과 열람 전에 고정했다.
2. 커버리지 최소선 90%/섹터별 80%는 fallback 결과와 무관하게 유지한다.
3. 금융리스 미공시를 0 또는 비중요로 간주하는 완화안을 폐기했다.
4. 이자부 D/E 실패 시 총부채비율을 대안 후보로 검토하되 혼합 사용을
   금지했다.
5. 모든 스크리너 리포트에 품질 판정 재무 데이터의 최신성을 표시하도록
   출력 계약을 추가했다.

수익률을 보거나 계산한 뒤에 이루어진 변경은 없다.

## 총부채와 D/E 정의

현재 검증 대상인 `총부채`는 재무 위험을 수반하는 이자부 금융부채다.

> 이자부 총부채 = 단기 이자부 차입금 + 유동성 장기부채 +
> 비유동 이자부 차입금 + 금융리스 부채

- 매입채무, 미지급비용, 충당부채 등 영업부채는 제외한다.
- 운용리스 부채는 제외한다.
- 금융리스가 장기부채 태그에 이미 포함된 경우 중복 합산하지 않는다.
- 구성요소가 API 또는 공시에 없다는 이유만으로 0을 대입하지 않는다.
- 공식 렌더링 재무상태표의 차원값과 커스텀 태그를 fallback으로 사용한다.
- 자기자본이 0 이하이면 D/E를 계산하지 않고 품질 게이트 미달로 처리한다.

기존 `MAX_DEBT_TO_EQUITY = 2.0`은 총부채의 포함 범위가 정의되지 않은
상태에서 제안된 값이므로 폐기한다.

## D/E 임계값 결정 규칙

수익률을 보지 않은 상태에서 다음 계산식을 고정한다.

1. 모집단은 기준일 현재 S&P 500 구성 발행사다.
2. 동일 CIK의 복수 주식종류는 하나의 발행사로 합친다.
3. Financials, Real Estate, Utilities를 제외한다.
4. 기준일 이전에 접수된 공시만 사용한다.
5. 동일 보고기간 말의 이자부 총부채와 자기자본을 사용한다.
6. 기준일로부터 200일 이내의 보고기간 말만 허용한다.
7. 자기자본이 양수이고 이자부 총부채 정의를 완전하게 복원한 발행사만
   D/E 분포에 넣는다.
8. 유효 표본의 D/E 90백분위수를 선형보간으로 계산하고 소수 둘째
   자리로 반올림해 `MAX_DEBT_TO_EQUITY`로 제안한다.

### 커버리지 분모와 해결 상태

- 전체 분모는 제외 섹터를 뺀 모든 발행사다.
- 자기자본이 0 이하이고 그 사실의 공시 출처가 확인된 기업은
  `해결됨—자동 미달`로 센다. D/E 분포에는 넣지 않는다.
- 자기자본이 양수인 기업은 엄격한 이자부 총부채가 복원돼야
  `해결됨`으로 센다.
- 공시 자체가 없거나 자기자본·총부채의 출처가 불완전하면 `미해결`이다.
- 전체 해결률 90% 이상, 각 포함 GICS 섹터 해결률 80% 이상이어야 한다.
- 사용한 모든 수치의 공시일과 접수번호 존재율은 100%여야 한다.
- 하나라도 미달하면 해당 D/E 분포는 편향된 표본으로 간주하고
  임계값을 확정하지 않는다.

현재 52.5% 해결 표본의 P90은 부채 항목을 같은 방식으로 공시하는 기업에
선택된 값일 수 있다. 미해결 기업이 추가되면 분포 자체가 달라질 수
있으므로 현재 P90은 임계값 근거가 아니다.

## fallback 결과에 따른 행동 규칙

다음 규칙은 주석·전체 XBRL fallback을 실행하기 전에 고정한다.

### 성공

아래를 모두 충족하면 이자부 D/E 정의를 유지한다.

- 전체 해결률 90% 이상
- 모든 포함 GICS 섹터 해결률 80% 이상
- 사용 사실의 공시일·접수번호 존재율 100%

이 경우에만 등록된 P90 계산식으로 `MAX_DEBT_TO_EQUITY`를 제안한다.

### 실패

하나라도 미달하면 다음을 적용한다.

1. 임계값을 정하지 않는다.
2. 전체 90% 또는 섹터별 80% 최소선을 낮추지 않는다.
3. 85% 등 관측 결과 바로 아래로 최소선을 재설정하지 않는다.
4. 금융리스 미공시를 0 또는 비중요로 간주하지 않는다.
5. 추가적인 기업별 예외나 휴리스틱으로 이자부 D/E를 계속 연명하지
   않는다.
6. 이자부 D/E 정의를 v1 품질 게이트 후보에서 철회하고, 부채 지표
   정의 자체를 대안으로 교체한다.
7. 교체 정의·분모·제외 규칙·임계값 계산식·커버리지 최소선은 수익률을
   보지 않은 상태에서 새 `PREREGISTRATION` 버전으로 등록한다.
8. 새 정의가 동결되기 전에는 수익률을 계산하지 않는다.

## 대안 부채 지표 후보

fallback 실패 시 가장 먼저 검토할 후보는 다음과 같다.

> 총부채비율 = 재무상태표의 총부채(`Liabilities`) ÷ 자기자본

- 총부채는 매입채무, 충당부채, 운용리스 등 비이자부 부채도 포함한다.
- 이자부 차입 위험만 측정하는 정확성은 낮아지지만, 재무상태표 필수
  합계 항목이므로 커버리지와 비교 가능성은 높을 것으로 예상한다.
- 현재 단계에서는 대안 후보일 뿐 채택된 정의가 아니다.
- 채택 시 자기자본 범위, 비지배지분 처리, 음수 자기자본 처리,
  동일 보고기간 규칙과 임계값 계산식을 새 버전에서 다시 등록한다.
- 대안의 임계값은 이자부 D/E의 2.0, 2.40, 2.60을 재사용하지 않고
  새 횡단면 분포에서 정한다.

### 혼합 금지

- 일부 종목에는 이자부 D/E, 다른 종목에는 총부채비율을 적용하지 않는다.
- 동일 실행·동일 백테스트에서는 모든 대상 기업에 하나의 부채 정의만
  사용한다.
- 어떤 정의를 쓸지는 종목별 데이터 가용성이나 통과 여부를 본 뒤
  선택하지 않는다.

## 금융리스 미공시 완화안 폐기

공식 렌더링 재무상태표에 금융리스가 별도로 나타나지 않으면 중요하지
않은 것으로 간주한 탐색안의 P90은 2.60이었다.

- 이 값은 결측을 0으로 처리하지 않는 원칙과 충돌한다.
- 엄격 표본 P90 2.40과의 차이가 이 예외를 정당화하지 않는다.
- 이 완화안은 민감도 기록으로만 보존하고 현재 스크리너나 백테스트에서
  사용하지 않는다.
- 향후 같은 완화안을 다시 채택하지 않는다. 지표가 실패하면 정의를
  통째로 교체한다.

## 매출총이익률 적신호의 결측 처리

이 규칙은 품질 게이트가 아니라 적신호 필터에만 적용한다.

1. `GrossProfit` 직접 사실을 우선한다.
2. 직접 사실이 없으면 매출과 원가의 범위가 동일하다는 것을 공시
   표시·주석으로 검증한 경우에만 `매출-원가`를 사용한다.
3. 검증 가능한 매출총이익률이 없으면 종목을 제외하지 않는다.
4. 대신 해당 적신호 하나만 적용하지 않고 결과와 로그에
   `GROSS_MARGIN_NOT_EVALUABLE`을 남긴다.
5. 이는 적신호가 없다는 뜻이 아니며 `통과`와 별도 상태로 집계한다.
6. 전체 및 섹터별 `평가 가능/평가 불가` 수를 모든 실행 리포트에
   표시한다.
7. 현재 스크리너와 백테스트에 같은 규칙을 사용한다.

품질 게이트의 필수 항목은 결측이면 계속 통과할 수 없다.

## 품질 재무 데이터 최신성 출력 계약

모든 현재 시점 스크리너와 백테스트 리포트 상단에 다음을 표시한다.

- `품질 판정 기준일`: 스크리너 또는 백테스트 기준일
- `재무 데이터 소스별 최신 접수분`: 예를 들어
  `SEC FSDS 2026 Q1`, `Companyfacts 2026-07-29 조회`
- `대상 종목 재무기준일 범위`: 사용된 가장 오래된 보고기간 말과
  가장 최신 보고기간 말
- `대상 종목 공시일 범위`: 사용된 접수일의 최소·최대

후보 결과 행에도 다음 열을 보존한다.

- `재무기준일`
- `공시일`
- `접수번호`
- `품질 데이터 상태`

기업마다 회계연도와 분기말이 다르므로, 리포트 상단의 공통 분기 표기만
사용하지 않고 종목별 실제 보고기간 말도 함께 표시한다.

## CIK 승계 처리

- 현재 티커–CIK 매핑이 이전 스냅샷과 달라지면 해당 종목의 계산을
  중단하고 승계 검토 대상으로 보낸다.
- 같은 티커라는 이유만으로 서로 다른 CIK를 자동 연결하지 않는다.
- 8-K12B, 10-12B 또는 이에 준하는 공식 공시에서 predecessor,
  successor, 효력일과 교환 관계를 확인한 경우에만 계보를 추가한다.
- 계보에는 효력일, 선행·후행 CIK, 근거 접수번호와 원문 URL을 보존한다.
- 백테스트 시점에는 그때 효력이 있던 CIK와 당시 공개된 공시만 사용한다.

## 현재 구현 범위

- 5년 historical PER은 현재 스크리너 완성 뒤 단계로 미룬다.
- 품질 게이트 전체 구현은 부채 지표 정의와 임계값이 확정된 뒤 시작한다.
- 임계값이나 커버리지 최소선을 성과 또는 관측 커버리지에 맞춰 조정하지
  않는다.
