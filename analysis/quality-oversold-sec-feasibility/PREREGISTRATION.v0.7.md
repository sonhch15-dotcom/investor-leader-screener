# 품질 우량주 과매도 스크리너 — 사전등록 v0.7

## 문서 상태

- 버전: 0.7
- 기록일: 2026-07-30
- 상위 문서: `PREREGISTRATION.v0.6.md`
- 상태: 전체 과거 커버리지 실행 전
- 이미 확인한 진단: 2013년 12월 단일 분기 스파이크
- 가격·수익률 접근 및 계산: 없음

이 문서는 v0.6의 90%·80%·100% 커버리지 기준, 가장 이른 60개월
연속 통과 창, P50 보정, 보정기간과 평가기간 비중복, 보유기간별
우측 검열 규칙을 변경하지 않는다. 전체 실행 전에 과거 구성표의 CIK
결측과 SEC 분기 자료의 월말 이월 방법만 고정한다.

## 월말 구성 발행사

각 월의 마지막 달력일 23:59:59 UTC 이전에 존재한 위키피디아
`List of S&P 500 companies` 문서의 마지막 리비전에서 구성표를 읽는다.
Financials, Real Estate, Utilities는 제외한다.

- 구성표에 숫자 CIK가 있으면 그 값을 우선한다.
- 같은 CIK의 복수 주식 종류는 한 발행사로 합친다.
- 같은 CIK에 서로 다른 포함 섹터가 연결되면 임의 선택하지 않고
  `CIK_SECTOR_CONFLICT`로 미해결 처리한다.
- 숫자 CIK가 없는 행을 현재 CIK 표나 현재 종목명으로 자동 승계하지
  않는다.

위키피디아 리비전은 구성 이력의 무료 근사 원천이다. 실제 지수 효력일과
문서 편집 시각이 다를 수 있는 한계를 결과에 기록한다.

## 숫자 CIK가 없는 과거 행의 연결

2014년 5월 이전처럼 구성표에 CIK 열이 없는 경우에만 SEC FSDS
`sub.txt`의 `instance` 파일명 접두어를 사용한다.

1. 종목코드와 인스턴스 접두어에서 영문자를 제외한 문자를 제거하고
   대문자로 정규화한다.
2. 월말 이전 250일 안에 접수된 10-K, 10-K/A, 10-Q, 10-Q/A 중
   정규화 접두어가 같은 접수의 CIK 집합을 구한다.
3. CIK가 정확히 하나일 때만 `UNIQUE_SEC_INSTANCE_TICKER`로 연결한다.
4. 후보가 없으면 `MISSING_SEC_INSTANCE_TICKER`, 둘 이상이면
   `AMBIGUOUS_SEC_INSTANCE_TICKER`로 미해결 처리한다.
5. 회사명 유사도, 현재 CIK, 수동 티커 승계표로 빈 연결을 채우지 않는다.

250일은 v0.4의 재무기간 신선도 한도와 같은 길이를 사용하지만, CIK
연결에서는 접수일 기준이다. 더 오래된 티커 사용과 티커 재사용에 따른
오연결을 동시에 제한하기 위한 데이터 계보 규칙이다.

## 월말 현재 최신 공시

공식 SEC Financial Statement Data Sets의 분기 ZIP을 접수분기 순서로
처리한다.

- 허용 서식: 10-K, 10-K/A, 10-Q, 10-Q/A
- 월말까지 접수된 공시만 상태에 반영
- 발행사별 최신 공시는 `(filed, accession)` 내림차순 첫 행
- 최신 공시의 보고기간 말이 월말보다 250일 넘게 오래되면
  `STALE_FINANCIAL_PERIOD`
- 최신 접수번호가 공식 재구성에 실패해도 더 오래된 접수번호로 후퇴 금지
- 수정공시는 별도 예외 없이 접수일 순서에 따라 원공시를 대체

재무사실 선택, 허용 태그, presentation 판정, 0.5% 회계등식 검사,
자기자본 0 이하 자동 미통과는 v0.4와 v0.4.1을 그대로 적용한다.

## 커버리지와 provenance

월별 모집단은 포함 섹터의 발행사다. 다음 두 상태만 판정 가능으로 센다.

- `RATIO_AVAILABLE`
- `NONPOSITIVE_EQUITY_AUTO_FAIL`

판정 가능한 모든 행은 공시일, 접수번호, 보고기간 말과 동일 접수번호의
사용 사실 계보를 가져야 한다. 그중 하나라도 없으면 provenance 미완결이다.

```python
MAX_FINANCIAL_PERIOD_AGE_DAYS = 250
MAX_TICKER_MAPPING_AGE_DAYS = 250
MIN_OVERALL_COVERAGE = 0.90
MIN_SECTOR_COVERAGE = 0.80
REQUIRED_PROVENANCE_RATE = 1.00
```

전체 90%, 모든 포함 섹터 80%, provenance 100% 중 하나라도 미달한
월은 부적격이다. 월을 삭제하거나 중간 연도를 제외하지 않는다.

## 실행 분리

과거 커버리지 프로그램은 구성 이력과 SEC 재무자료만 읽는다. 가격,
수정주가, 배당, SPY, 수익률 및 미래 보유기간 결과를 읽거나 출력하지
않는다.

커버리지 원장, 최초 60개월 창과 P50 결과를 별도 커밋과 원격 태그로
고정한 뒤에만 독립된 가격 프로세스를 만들 수 있다.
