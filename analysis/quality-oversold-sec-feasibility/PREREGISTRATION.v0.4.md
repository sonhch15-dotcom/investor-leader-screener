# 품질 우량주 과매도 스크리너 — 사전등록 v0.4

## 문서 상태

- 버전: 0.4
- 기록일: 2026-07-30
- 상태: 연결 총부채 비율의 현재 횡단면 커버리지·분포 조회 직전
- 수익률 결과 열람·계산: 없음
- 현재 분포 열람·계산: 없음
- 백테스트용 부채 임계값: 미확정
- 대체 사유: 이자부 D/E 정의가 v0.3의 전체 90%·섹터별 80%
  커버리지 최소선에 미달했다.

이 문서는 현재 횡단면 분포를 계산하기 전에 정의, 재구성 공식,
커버리지 최소선, 미래정보 방지 규칙과 실패 시 행동을 고정한다.

## 정확도보다 커버리지를 택한 이유

v0.3의 이자부 부채는 재무 위험의 원인인 차입금과 금융리스를 직접
측정한다는 점에서 이론적으로 더 정확했다. 그러나 모든 필요한 구성요소를
명시적으로 복원한 발행사가 전체 모집단의 36.7%뿐이어서 품질 게이트에
사용할 수 없었다.

v0.4는 다음의 연결 총부채를 사용한다.

> 연결 총부채 = 재무상태표의 모든 부채

여기에는 이자부 차입금과 금융리스뿐 아니라 매입채무, 미지급금,
충당부채, 계약부채, 세금부채와 운용리스 부채 등이 포함된다. 따라서
사업모델과 운전자본 구조가 섞이고 업종 간 비교 정확도가 낮아진다.

이는 **정확도를 일부 포기하고, 모든 대상 기업에 동일하게 적용할 수 있는
커버리지를 택한 결정**이다. 백테스트 결과가 애매할 경우 이 정의 변경은
성과 차이의 원인 후보로 명시한다.

## 품질 게이트의 새 재무 안정 지표

지표는 다음과 같이 정의한다.

> 총부채비율 = 연결 총부채 ÷ 비지배지분 포함 연결 자기자본

코드 상수명은 기존 D/E와 혼동하지 않도록 다음처럼 분리한다.

```python
LEVERAGE_METRIC = "total_liabilities_to_total_equity"
MAX_TOTAL_LIABILITIES_TO_EQUITY = None
```

기존 `MAX_DEBT_TO_EQUITY = 2.0`, 탐색 표본의 2.40과 2.60은 폐기하고
새 지표에서 재사용하지 않는다.

## 허용하는 표준 사실과 동등 재구성

동일 발행사, 동일 보고기간 말, 동일 접수번호의 entity-wide USD 사실만
결합한다. custom 태그, 차원별 부분합, 종목별 예외와 결측 0 대입은
허용하지 않는다.

다음 세 재무상태표 총계를 사용한다.

- `L`: `us-gaap:Liabilities`
- `E`: 비지배지분 포함 연결 자기자본
- `T`: `us-gaap:LiabilitiesAndStockholdersEquity`

`E`는 다음 순서로 복원한다.

1. `us-gaap:StockholdersEquityIncludingPortionAttributableToNoncontrollingInterest`
2. 위 사실이 없고 아래 두 사실이 모두 명시된 경우에만 합산
   - `us-gaap:StockholdersEquity`
   - `us-gaap:MinorityInterest`

`L`, `E`, `T` 중 동일 접수번호·보고기간 말에 두 개 이상이 있으면
회계등식 `T = L + E`를 사용해 나머지 하나를 재구성할 수 있다.

- `L`과 `E`가 있으면 직접 사용
- `L`과 `T`가 있으면 `E = T - L`
- `E`와 `T`가 있으면 `L = T - E`

세 값이 모두 있으면 다음 일치 검사를 먼저 통과해야 한다.

```text
abs(T - (L + E)) / max(abs(T), 1 USD) <= 0.005
```

0.5% 허용치는 표시 단위와 반올림 차이를 위한 것이며, 기준을 넘으면
해당 접수번호의 지표는 계산하지 않는다.

직접 `E`와 `StockholdersEquity + MinorityInterest`가 모두 있으면 같은
0.5% 일치 검사를 적용한다. 동일 태그·접수번호·보고기간에 서로 다른
복수 값이 있으면 임의로 하나를 고르지 않고 해당 사실을 충돌로 처리한다.

현재 점검에서는 조회 기준일 이전에 제출된 10-K, 10-K/A, 10-Q, 10-Q/A
중 가장 최근 접수번호의 가장 최근 보고기간 말만 사용한다. 최신 보고기간
말이 조회 기준일보다 250일 넘게 오래되면 미해결로 처리한다. 최신
접수번호가 미해결이라는 이유로 더 오래된 접수번호로 후퇴하지 않는다.

## 유효성 및 결측 처리

- `L < 0`: 데이터 오류로 보고 미해결
- `E <= 0`: 비율을 계산하지 않고 재무 안정 게이트 자동 미통과
- `L`, `E`, `T` 중 두 개 미만: 미해결
- 태그 부재를 0으로 처리하지 않음
- `MinorityInterest` 부재를 0으로 처리하지 않음
- 서로 다른 접수번호 또는 보고기간의 사실을 섞지 않음
- 직접 사실과 재구성 값은 같은 개념의 동등 공식이며 종목별로 다른
  부채 지표를 적용한 것으로 보지 않음

각 결과에는 보고기간 말, 공시일, 접수번호, 사용 태그, 직접·재구성 공식과
데이터 상태를 기록한다.

## 현재 횡단면 데이터 점검

대상은 현재 구성 종목에서 Financials, Real Estate, Utilities를 제외하고,
동일 CIK의 복수 주식종류를 하나의 발행사로 합친 362개 발행사다.

현재 점검은 다음만 결정한다.

1. 새 정의가 전체 90% 이상에서 판정 가능한가
2. 각 포함 GICS 섹터가 80% 이상에서 판정 가능한가
3. 사용 사실의 공시일과 접수번호 존재율이 100%인가
4. 현재 횡단면 분포의 형태와 이상치가 데이터 오류를 시사하는가

`E <= 0`이 공식 사실로 확인된 기업은 비율 분포에서는 제외하지만,
게이트 자동 미통과로 판정 가능 집단에는 포함한다.

현재 횡단면 P90을 포함한 분위수는 데이터 품질 진단용으로만 보고한다.
현재 값은 백테스트 임계값이나 실전 게이트에 사용하지 않는다.

## 백테스트 임계값의 미래정보 방지 규칙

현재 2026년 횡단면에서 계산한 분위수를 과거 신호일에 적용하지 않는다.
백테스트용 절대 임계값은 최초 신호일 이전 데이터만으로 한 번 계산한다.

```python
CALIBRATION_MONTHS = 60
LEVERAGE_THRESHOLD_QUANTILE = 0.90
```

계산 절차는 다음과 같다.

1. 최초 백테스트 신호일 직전 월말부터 거슬러 올라간 60개 연속 월말을
   보정기간으로 고정한다.
2. 각 월말의 당시 S&P 500 구성 발행사를 복원하고 동일 섹터를 제외한다.
3. 각 월말에 실제로 공시되어 있던 최신 재무사실만 사용한다.
4. 각 월말마다 전체 90%, 각 포함 섹터 80%, 공시일·접수번호 100%
   최소선을 모두 확인한다.
5. 60개 월말 중 하나라도 최소선에 미달하면 임계값 보정은 무효다.
   월을 빼거나 보정기간 길이를 바꾸지 않는다.
6. 자기자본이 양수인 모든 유효 발행사-월 관측치를 하나의 사전 보정
   분포로 합친다.
7. 그 분포의 선형보간 P90을 절대 임계값으로 한 번 계산한다.
8. 계산에는 원시 정밀도를 그대로 사용하고, 보고서 표시만 소수 둘째
   자리로 반올림한다.
9. 계산된 절대값은 모든 백테스트 신호일에 동일하게 적용한다.

최초 백테스트 신호일은 백테스트 최종 사전등록에서 수익률 계산 전에
확정한다. 신호일이 확정되기 전에는
`MAX_TOTAL_LIABILITIES_TO_EQUITY`를 계산하지 않는다.

## 새 정의도 커버리지에 실패할 때의 행동

현재 횡단면에서 전체 90%, 섹터별 80%, provenance 100% 중 하나라도
미달하면 다음을 적용한다.

1. 부채 지표를 세 번째 정의로 다시 교체하지 않는다.
2. 커버리지 최소선이나 0.5% 일치 허용치를 낮추지 않는다.
3. custom 태그, 종목별 예외 또는 결측 0 대입으로 비율을 연명하지 않는다.
4. 현재 커버리지와 실패 사유만 공개하고 수익률 계산을 시작하지 않는다.
5. 커버리지 확인 후 수익률 계산 전에 아래 둘 중 하나를 명시적으로
   선택하고 새 사전등록 버전에 기록한다.
   - 재무 안정 항목을 품질 게이트에서 제외하고 그 사실과 사유를 명시
   - 무료 데이터로는 요구 사양을 충족할 수 없다고 판정하고 프로젝트 중단

위 두 선택지 외에 다른 부채 지표를 탐색하지 않는다.

## 성공 시 다음 행동

현재 횡단면 커버리지와 provenance가 모두 통과하면:

1. 총부채비율 정의를 v1 품질 게이트의 재무 안정 지표로 유지한다.
2. 현재 횡단면 분위수는 진단 결과로만 기록한다.
3. 백테스트 시작일과 60개월 사전 보정기간의 데이터 유효성을 별도로
   확인한다.
4. 백테스트 최종 사전등록이 완료되기 전에는 수익률을 계산하지 않는다.

## 유지되는 이전 결정

- 품질 게이트 필수 항목의 결측은 미통과
- 매출총이익률 적신호는 평가 가능·발동·평가 불가의 3상태
- `GROSS_MARGIN_NOT_EVALUABLE`은 종목 전체 제외 사유가 아님
- CIK 승계는 공식 공시 근거가 있을 때만 등록
- 현재 스크리너와 백테스트는 같은 재무 정의와 결측 규칙 사용
- 5년 historical PER는 후속 단계로 유지
