## 원인

기존 계산은 다음 경우에 공시되지 않은 구성요소를 사실상 0으로
간주해 엄격 완결로 잘못 분류했다.

1. 유동성 장기부채와 비유동 부채가 있지만 단기차입금이 없는 경우
2. 비유동 부채와 금융리스가 있지만 유동 부채가 없는 경우
3. 금융리스 부채만 확인되고 일반 차입금이 확인되지 않은 경우
4. `ShortTermBorrowings`보다 좁은 항목을 전체 유동 부채처럼 사용한 경우
5. 전체 장기부채에 유동 부채 확인 없이 금융리스를 더한 경우

이는 “결측을 0으로 처리하지 않는다”는 등록 원칙에 어긋난다.

## 수정된 엄격 완결 공식

다음과 같이 모든 필요한 구성요소가 명시적으로 확인되는 경우만
엄격 완결로 인정한다.

1. 이자부 부채와 금융리스를 합친 직접 총액
2. 전체 유동부채성 차입금 + 금융리스를 포함한 비유동 장기부채
3. 단기차입금 + 금융리스를 포함한 유동 장기부채 +
   금융리스를 포함한 비유동 장기부채
4. 단기차입금 + 금융리스를 포함한 전체 장기부채
5. 단기·장기 순수 차입금 총액 + 별도 금융리스 총액
6. 전체 유동부채성 차입금 + 순수 비유동 장기부채 +
   별도 비유동 금융리스
7. 단기차입금 + 유동 장기부채 + 비유동 장기부채 +
   별도 금융리스 총액
8. 단기차입금 + 전체 장기부채 + 별도 금융리스 총액

각 공식에서 필요한 사실 하나라도 없으면 엄격 완결로 인정하지 않는다.
명시적으로 공시된 0은 사용할 수 있지만, 항목 부재를 0으로 바꾸지 않는다.
