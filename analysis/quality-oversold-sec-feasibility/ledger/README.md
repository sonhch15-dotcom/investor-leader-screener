# 전향 추적 원장

> 검증된 성과 우위 없음 · 조사 후보 목록

이 원장은 매월 첫 거래일에 발생한 품질 과매도 신호를 전향적으로
보존한다. 백테스트를 대체하거나 성과 우위를 주장하지 않는다.

## 디렉터리

- `signals/YYYY-MM-DD.json`: 월간 신호 스냅샷. 절대 덮어쓰지 않는다.
- `entries/YYYY-MM-DD.json`: 다음 거래일 시가가 확정된 뒤 추가하는
  진입가격 파일. 원본 신호 스냅샷은 수정하지 않는다.
- `outcomes/63|126|252/YYYY-MM-DD.json`: 해당 보유기간이 완결된
  월별 코호트 성과. 한 번 생성한 파일은 덮어쓰지 않는다.
- `performance.md`: 완결 성과 파일을 월별 동일가중으로 집계한
  현재 보고서.
- `corrections/YYYY-MM-DD.N.json`: 오류 정정 파일. 원본, 사유,
  수정 코드 버전을 명시한다.

## 스냅샷 규칙

- S&P 500의 해당 월 첫 거래일에만 생성한다.
- 신호가 0개여도 퍼널과 시장 폭을 기록한다.
- 각 종목의 섹터 낙폭 중앙값과 S&P 500 구성종목 전체 낙폭
  중앙값을 숫자로 기록한다.
- 종목 낙폭/섹터 중앙값 비율과 섹터별 표본 수·Q1·중앙값·Q3를
  함께 기록해 `1.3` 경계에 가까운 판정을 식별할 수 있게 한다.
- 감시목록 중 낙폭 15~40% 종목 수·전체 수·비율을 기록한다.
- 추세 및 하락원인 태그 분포를 기록하되 표본이 쌓이기 전에는
  해석하지 않는다.
- 다음 거래일 시가는 신호일에 알 수 없으므로 최초 파일에는
  `PENDING_NEXT_TRADING_DAY_OPEN`으로 기록하고 별도 `entries` 파일로
  추가한다.
- 원본 파일을 덮어쓰지 않는다.

## 성과 갱신 규칙

- `update_performance.py`가 다음 거래일 SPY 세션을 확인한 뒤 종목과
  SPY의 원시 시가 및 당시 조정계수를 `entries`에 추가한다.
- 63·126·252번째 SPY 거래일 종가가 생긴 트랙만 완결한다. 미완결
  트랙은 `RIGHT_CENSORED`이며 수익률을 계산하지 않는다.
- 종목 수익률은 배당 포함 조정주가 기준이며 코호트 안에서
  동일가중한다. 전체 집계도 월별 코호트 간 동일가중한다.
- 완결 코호트가 트랙별 20개 미만이면 `performance.md`에는
  `표본 부족(N/20)`만 표시하고 평균 수익률을 표시하지 않는다.
- 공통 거래일은 완결됐지만 종목 가격이 없으면 해당 코호트를
  부분 집계하지 않는다. `DATA_INCIDENT_REVIEW_REQUIRED`로 기록해
  상장폐지·인수·티커 변경 또는 데이터 오류를 확인한다.
