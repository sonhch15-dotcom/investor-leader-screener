# 품질 우량주 과매도 스크리너 — 사전등록 v0.2

## 문서 상태

- 버전: 0.2
- 기록일: 2026-07-29
- 상태: 데이터 정의·커버리지 검증 단계
- 수익률 결과 열람: 없음
- `MAX_DEBT_TO_EQUITY`: **미확정**
- 주의: 이 파일은 최종 사전등록이 아니다. 데이터 커버리지 허용선을
  통과하고 수익률 계산을 시작하기 직전에 최종본을 별도 버전으로 만들고,
  원격 저장소에 푸시한 커밋과 서명 태그를 리포트에 인용한다.

## v0.1에서 바뀐 내용

1. D/E 커버리지에서 자기자본 비양수 기업의 처리 방식을 명확히 했다.
2. 매출총이익률 적신호가 계산 불가능한 경우의 처리 규칙을 확정했다.
3. Companyfacts와 SEC 렌더링 데이터의 관측 커버리지를 기록했다.
4. 완화된 D/E 정의에서 얻은 P90은 민감도 값일 뿐 임계값이 아님을
   명시했다.

수익률을 보거나 계산한 뒤에 이루어진 변경은 없다.

## 총부채와 D/E 정의

`총부채`는 재무 위험을 수반하는 이자부 금융부채로 한정한다.

> 총부채 = 단기 이자부 차입금 + 유동성 장기부채 +
> 비유동 이자부 차입금 + 금융리스 부채

- 매입채무, 미지급비용, 충당부채 등 영업부채는 제외한다.
- 운용리스 부채는 제외한다.
- 금융리스가 장기부채 태그에 이미 포함된 경우 중복 합산하지 않는다.
- 구성요소가 API 응답에 없다는 이유만으로 0을 대입하지 않는다.
- 공식 렌더링 재무상태표의 차원값과 커스텀 태그를 fallback으로 사용한다.
- 자기자본이 0 이하이면 D/E를 계산하지 않고 품질 게이트 미달로 처리한다.

기존 `MAX_DEBT_TO_EQUITY = 2.0`은 총부채의 포함 범위가 정의되지 않은
상태에서 제안된 값이므로 폐기한다.

## D/E 임계값 결정 규칙

수익률을 보지 않은 상태에서 다음 계산식을 고정한다.

1. 모집단은 기준일 현재 S&P 500 구성 발행사다.
2. 동일 CIK의 복수 주식종류는 하나의 발행사로 합친다.
3. Financials, Real Estate, Utilities를 제외한다.
4. 기준일 이전에 접수된 공시만 사용한다.
5. 동일 보고기간 말의 총부채와 자기자본을 사용한다.
6. 기준일로부터 200일 이내의 보고기간 말만 허용한다.
7. 자기자본이 양수이고 총부채 정의를 완전하게 복원한 발행사만 D/E
   분포에 넣는다.
8. 유효 표본의 D/E 90백분위수를 선형보간으로 계산하고 소수 둘째
   자리로 반올림해 `MAX_DEBT_TO_EQUITY`로 제안한다.

### 커버리지 분모와 해결 상태

- 전체 분모는 제외 섹터를 뺀 모든 발행사다.
- 자기자본이 0 이하이고 그 사실의 공시 출처가 확인된 기업은
  `해결됨—자동 미달`로 센다. D/E 분포에는 넣지 않는다.
- 자기자본이 양수인 기업은 엄격한 총부채가 복원돼야 `해결됨`으로 센다.
- 공시 자체가 없거나 자기자본·총부채의 출처가 불완전하면 `미해결`이다.
- 전체 해결률 90% 이상, 각 포함 GICS 섹터 해결률 80% 이상이어야 한다.
- 사용한 모든 수치의 공시일과 접수번호 존재율은 100%여야 한다.
- 하나라도 미달하면 분포는 탐색 결과로만 보고하고 임계값을 확정하지
  않는다.

### 2026-07-29 현재 관측 결과

- Companyfacts 비차원 표준 태그만 엄격하게 사용:
  79/362 발행사에서 D/E 계산 가능
- SEC 2026 Q1 공식 렌더링 재무제표와 Companyfacts의 금융리스 사실을
  결합:
  163/362 발행사에서 엄격한 D/E 계산 가능
- 자기자본 비양수 27개를 `해결됨—자동 미달`로 더해도
  190/362로 전체 90%에 미달
- 따라서 `MAX_DEBT_TO_EQUITY`는 미확정이다.

공식 렌더링 재무상태표에 금융리스가 별도로 나타나지 않으면 중요하지
않은 것으로 간주하는 완화안에서는 P90이 2.60이었다. 그러나 이 방식은
엄격한 총부채 정의 및 결측값 원칙과 다르므로 **민감도 참고값일 뿐
임계값으로 채택하지 않는다.**

## 매출총이익률 적신호의 결측 처리

이 규칙은 품질 게이트가 아니라 적신호 필터에만 적용한다.

1. `GrossProfit` 직접 사실을 우선한다.
2. 직접 사실이 없으면 매출과 원가의 범위가 동일하다는 것을 공시
   표시·주석으로 검증한 경우에만 `매출-원가`를 사용한다.
3. 검증 가능한 매출총이익률이 없으면 종목을 제외하지 않는다.
4. 대신 해당 적신호 하나만 적용하지 않고 결과와 로그에
   `GROSS_MARGIN_NOT_EVALUABLE`을 남긴다.
5. 이는 적신호가 없다는 뜻이 아니며 `통과`와 별도 상태로 집계한다.
6. 전체 및 섹터별 `평가 가능/평가 불가` 수를 모든 실행 리포트에
   표시한다.
7. 현재 스크리너와 백테스트에 같은 규칙을 사용한다.

이 결정의 근거는 다음과 같다.

- 제외 섹터를 뺀 362개 발행사 중 최근 8개 분기에 직접 `GrossProfit`이
  모두 있는 기업은 173개(47.8%)다.
- Energy는 0/21, Communication Services는 2/20이다.
- 검증하지 않은 `매출-원가` 후보까지 포함한 상한도 264/362(72.9%)다.
- CAT은 두 태그가 모두 있어도 매출과 원가 범위가 달라 단순 차감이
  잘못되며, XOM과 LIN은 비교 가능한 총매출이익을 공시하지 않는다.

따라서 데이터 부족을 위험 신호로 간주해 제외하면 여러 섹터를 구조적으로
축소하게 된다.

## CIK 승계 처리

- 현재 티커–CIK 매핑이 이전 스냅샷과 달라지면 해당 종목의 계산을
  중단하고 승계 검토 대상으로 보낸다.
- 같은 티커라는 이유만으로 서로 다른 CIK를 자동 연결하지 않는다.
- 8-K12B, 10-12B 또는 이에 준하는 공식 공시에서 predecessor,
  successor, 효력일과 교환 관계를 확인한 경우에만 계보를 추가한다.
- 계보에는 효력일, 선행·후행 CIK, 근거 접수번호와 원문 URL을 보존한다.
- 백테스트 시점에는 그때 효력이 있던 CIK와 당시 공개된 공시만 사용한다.

## 현재 구현 범위

- 5년 historical PER은 제외하지 않고 현재 스크리너 완성 뒤 단계로
  미룬다.
- 품질 게이트와 나머지 적신호 필터 구현은 D/E 미해결 범위를 추가로
  검토한 뒤 시작한다.
- 임계값을 성과 개선 목적으로 조정하지 않는다.
