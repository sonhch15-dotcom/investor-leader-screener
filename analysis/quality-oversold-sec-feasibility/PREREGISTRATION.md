# 품질 우량주 과매도 스크리너 — 사전등록

## 문서 상태

- 버전: 0.1
- 기록일: 2026-07-29
- 상태: 재무 데이터 정의·커버리지 검증 단계
- 수익률 결과 열람: 없음
- 주의: 신규 독립 저장소가 확정되면 이 문서를 이관하고 원격 태그로
  고정한다. 현재 파일은 로컬 작업 기록이며 시간 증명의 효력은 없다.

## 총부채와 D/E 정의

`총부채`는 재무 위험을 나타내는 이자부 금융부채로 한정한다.

> 총부채 = 단기 이자부 차입금 + 유동성 장기부채 +
> 비유동 이자부 차입금 + 금융리스 부채

- 매입채무, 미지급비용, 충당부채 등 영업부채는 제외한다.
- 운용리스 부채는 제외한다.
- 금융리스가 장기부채 태그에 이미 포함된 경우 중복 합산하지 않는다.
- 구성요소가 공시에서 확인되지 않으면 0으로 채우지 않는다.
- 자기자본이 0 이하이면 D/E를 계산하지 않고 품질 게이트 미달로 처리한다.

기존 `MAX_DEBT_TO_EQUITY = 2.0`은 총부채의 포함 범위가 정의되지 않은
상태에서 정해졌으므로 폐기한다. 새 임계값은 아래의 수익률 비의존
횡단면 규칙으로 한 번만 정한다.

## D/E 임계값 산정 규칙

분포를 확인하기 전에 다음 규칙을 고정한다.

1. 모집단은 기준일 현재 S&P 500 구성 종목이다.
2. 동일 CIK의 복수 주식종류는 하나의 발행사로 합친다.
3. Financials, Real Estate, Utilities는 임계값 산정과 스크리닝에서
   제외한다.
4. 기준일 이전에 공시된 사실만 사용한다.
5. 동일 분기 말의 총부채와 자기자본을 사용한다.
6. 분기 말은 기준일로부터 200일 이내여야 한다.
7. 자기자본이 양수이고 총부채 정의를 완전하게 복원한 발행사만
   유효 표본으로 센다.
8. `MAX_DEBT_TO_EQUITY`는 유효 표본 D/E의 90백분위수를 선형보간으로
   계산한 뒤 소수 둘째 자리로 반올림한다.

90백분위수는 포함 시장에서 이자부 레버리지가 가장 높은 상위 10%를
`과다 차입`으로 분류한다는 사전적 의미다. 반올림 외에 결과를 보고
분위수나 계산식을 바꾸지 않는다.

### 임계값 유효성 조건

- 포함 대상 발행사 전체 커버리지 90% 이상
- 각 포함 GICS 섹터 커버리지 80% 이상
- CIK 연결 성공률, 공시일 존재율, 접수번호 존재율은 각각 100%

하나라도 미달하면 D/E 분포는 탐색 결과로만 보고
`MAX_DEBT_TO_EQUITY`를 확정하지 않는다. 실제 관측치 바로 아래로
허용선을 옮기지 않는다.

## 매출총이익률 적신호의 결측 처리

아래 두 방식 중 어느 것을 사용할지는 원문 inline XBRL fallback의
S&P 500 커버리지를 확인한 뒤, 수익률 계산 전에 확정한다.

1. 데이터 부족이면 종목 제외
2. 해당 적신호만 미적용하고 결과에 `매출총이익률 검증 불가` 태그 표시

현재 단계에서는 어느 방식도 선택하지 않는다. 품질 게이트의 결측은
이 결정과 무관하게 `데이터 부족`으로 분리하고 통과시키지 않는다.

## CIK 승계 처리

- 현재 티커-CIK 매핑이 이전 스냅샷과 달라지면 해당 종목의 재무 계산을
  중단하고 승계 검토 대상으로 보낸다.
- 티커가 같다는 이유만으로 서로 다른 CIK를 자동 연결하지 않는다.
- 8-K12B, 10-12B 또는 이에 준하는 공식 공시에서 predecessor,
  successor, 효력일과 교환 관계를 확인한 경우에만 계보에 추가한다.
- 계보에는 효력일, 선행·후행 CIK, 근거 접수번호와 원문 URL을 보존한다.
- 백테스트는 신호일 현재 효력이 있는 CIK와 당시 공개된 공시만 사용한다.

## 현재 구현 범위

- 5년 historical PER은 삭제하지 않고 핵심 현재 스크리너 이후 단계로
  미룬다.
- 품질 게이트·적신호 필터 구현은 이번 fallback·횡단면 검증을
  검토받은 뒤 시작한다.
- 임계값을 성과 개선 목적으로 조정하지 않는다.
